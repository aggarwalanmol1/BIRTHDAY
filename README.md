# 🎂 Birthday Studio

### Create unforgettable birthday experiences with personalized websites!

Birthday Studio is a personalized birthday website generator that allows users to create beautiful, interactive birthday experiences for their friends and loved ones.

Instead of sending an ordinary birthday message, create a complete website with animations, photos, personalized messages and password-protected access.

## ✨ Features

- 🎂 Personalized birthday websites
- 🥚 Interactive egg-opening introduction
- 📖 Five-page birthday experience
- 📸 Photo gallery supporting up to 4 photos
- 🎨 Multiple customizable themes
- 🔐 Password-protected birthday pages
- 💌 Personalized birthday messages
- 🔗 Unique shareable birthday links

## 🛠️ Tech Stack

| Technology | Purpose |

## 🚀 Deployment

The project is deployed using Vercel and connected to GitHub.

- Hosting: Vercel
- Storage: Private Vercel Blob
- Backend: Vercel Functions

## 🔒 Security

- Creator access is protected using an environment variable.
- Birthday viewing requires a separate password.
- Private Blob storage keeps uploaded photos and birthday records protected.
- Sensitive credentials are not stored in frontend files.
